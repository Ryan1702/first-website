# 合并两个有序数组

## 题目描述

给定两个长度分别为 n、m 的非递减整数序列 a、b，请把它们合并成一个非递减序列并输出。

## 输入格式

第一行两个整数 n, m。

第二行 n 个整数，表示序列 a。

第三行 m 个整数，表示序列 b。

## 输出格式

输出一行 n + m 个整数，表示合并后的非递减序列，相邻整数之间用一个空格分隔。

## 数据范围

- 1 ≤ n, m ≤ 2 × 10^5
- |a_i| ≤ 10^9，|b_i| ≤ 10^9
- 输入保证 a、b 均为非递减序列

## 样例

```text title="样例输入"
3 2
1 3 5
2 4
```

```text title="样例输出"
1 2 3 4 5
```

## 思路

两个指针 i、j 分别指向 a、b 当前待比较的元素，每次把较小者放入结果数组并让对应指针后移；相等时优先取 a 的元素，保证合并结果稳定。当其中一个序列先用完，就把另一个序列剩余的元素依次追加到结果末尾。

时间复杂度 O(n + m)。

## 代码

```cpp
#include <bits/stdc++.h>
using namespace std;
int main()
{
    int n, m; // n 为数组 a 的长度，m 为数组 b 的长度
    cin >> n >> m;

    vector<int> a(n), b(m); // 定义两个有序数组（假设输入已按非递减排序）
    for (int i = 0; i < n; i++)
    {
        cin >> a[i];
    }
    for (int j = 0; j < m; j++)
    {
        cin >> b[j];
    }

    vector<int> res; // 存放合并后的有序序列
    int i = 0;       // 指向数组 a 当前待比较元素的指针
    int j = 0;       // 指向数组 b 当前待比较元素的指针

    // 当两个指针都还在各自数组范围内时，比较并选出较小者
    while (i < n && j < m)
    {
        if (a[i] <= b[j])
        { // 用 <= 保证相等时优先取 a[i]，逻辑清晰且稳定
            res.push_back(a[i]);
            i++; // 移动 a 的指针
        }
        else
        {
            res.push_back(b[j]);
            j++; // 移动 b 的指针
        }
    }

    // 如果数组 a 还有剩余元素，直接按顺序追加到 res
    while (i < n)
    {
        res.push_back(a[i]);
        i++;
    }

    // 如果数组 b 还有剩余元素，直接按顺序追加到 res
    while (j < m)
    {
        res.push_back(b[j]);
        j++;
    }

    // 输出合并后的结果
    for (int k = 0; k < (int)res.size(); k++)
    {
        if (k > 0)
        {
            cout << " ";
        }
        cout << res[k];
    }
    cout << "\n";

    return 0;
}
```
