# 移除数组中的零

## 题目描述

给定一个长度为 $n$ 的整数数组 $a_1, a_2, \dots, a_n$，请把其中所有值为 $0$ 的元素移到数组末尾，同时保持非零元素之间的相对顺序不变。输出处理后的数组（长度仍为 $n$）。

## 输入格式

第一行一个整数 $n$。

第二行 $n$ 个整数 $a_1, a_2, \dots, a_n$。

## 输出格式

输出一行 $n$ 个整数，表示处理后的数组，相邻整数之间用一个空格分隔。

## 数据范围

- $1 \le n \le 2 \times 10^5$
- $|a_i| \le 10^9$

## 样例

```text title="样例输入"
5
0 1 0 3 12
```

```text title="样例输出"
1 3 12 0 0
```

## 思路

用快慢指针，在数组内部原地完成：

- $\text{slow}$ 指向下一个非零元素应该放的位置；
- $\text{fast}$ 从头到尾扫描，遇到非零元素就写到 $a[\text{slow}]$ 并让 $\text{slow}$ 后移，遇到 $0$ 直接跳过；
- 扫描结束后，把 $[\text{slow}, n-1]$ 这一段全部填成 $0$。

每个元素只访问一次，时间复杂度 $O(n)$，额外空间 $O(1)$。

## 代码

```cpp
#include <bits/stdc++.h>
using namespace std;
int main()
{
    int n;    // 数组长度
    cin >> n; // 读入 n

    vector<int> a(n); // 定义长度为 n 的数组 a
    for (int i = 0; i < n; i++)
    {
        cin >> a[i]; // 读入数组元素
    }

    int slow = 0; // 慢指针：指向下一个“非零元素”应该存放的位置

    // 快指针 fast 从头到尾遍历数组中的每一个元素
    for (int fast = 0; fast < n; fast++)
    {
        if (a[fast] != 0)
        {                      // 如果当前扫描到的元素不是 0
            a[slow] = a[fast]; // 把这个非零元素放到 slow 指向的位置
            slow++;            // slow 后移一位，准备接收下一个非零元素
        }
        // 如果 a[fast] == 0，则跳过不处理，让 fast 继续往后找非零元素
    }

    // 此时 [0, slow - 1] 已经按原顺序放好了所有非零元素
    // 将剩余位置 [slow, n - 1] 全部填为 0
    for (int i = slow; i < n; i++)
    {
        a[i] = 0;
    }

    // 按规范格式输出处理后的数组（元素之间用单个空格分隔，末尾换行）
    for (int i = 0; i < n; i++)
    {
        if (i > 0)
        {
            cout << " "; // 第 2 个及以后的元素前输出一个空格，避免行末多余空格
        }
        cout << a[i];
    }
    cout << "\n";

    return 0;
}
```
