# 连续子段和为 k 的个数

## 题目描述

给定一个长度为 n 的非负整数序列 a 和一个整数 k，求有多少个连续子段（区间）的元素和恰好等于 k。

## 输入格式

第一行两个整数 n, k。

第二行 n 个整数 a_1, a_2, …, a_n。

## 输出格式

一行一个整数，表示和恰好为 k 的连续子段个数。

## 数据范围

- 1 ≤ n ≤ 2 × 10^5
- 0 ≤ a_i ≤ 10^9
- 0 ≤ k ≤ 10^18

## 样例

```text title="样例输入"
5 7
1 2 3 4 3
```

```text title="样例输出"
2
```

**样例解释**

满足条件的子段是 [3, 4]（下标从 1 开始计为第 3、4 个元素）和 [4, 3]（第 4、5 个元素）。

## 思路

所有元素非负，所以区间和随着左端点右移只会变小，适合用滑动窗口。

维护窗口 [l, r] 与窗口和 sum：右端点 r 每次右移并把 a[r] 并入 sum；当 sum > k 时不断把 a[l] 移出窗口（l 右移），直到 sum ≤ k；调整完若 sum == k，说明以 r 结尾、左端为当前 l 的区间和正好为 k，答案加一。

每个元素最多进出窗口一次，时间复杂度 O(n)。注意这个做法依赖「元素非负」，若存在负数则不成立。

## 代码

```cpp
#include <bits/stdc++.h>
using namespace std;
int main()
{
    int n;         // 数组元素个数
    long long k;   // 目标子段和（用 long long 避免和较大时溢出）
    cin >> n >> k; // 读入 n 和 k

    vector<long long> a(n); // 存储数组元素，使用 long long 防止累加时溢出
    for (int i = 0; i < n; i++)
    {
        cin >> a[i]; // 读入第 i 个元素
    }

    long long ans = 0; // 记录和恰好等于 k 的连续子段数量
    long long sum = 0; // 维护当前窗口 [l, r] 内所有元素的和
    int l = 0;         // 滑动窗口的左边界（慢指针/左指针）

    // r 作为滑动窗口的右边界，从 0 到 n-1 逐步向右扩展
    for (int r = 0; r < n; r++)
    {
        sum += a[r]; // 将新纳入窗口的元素 a[r] 加入当前区间和

        // 如果当前窗口和超过了 k，就不断从左边移出元素（l++），缩小窗口
        // l <= r 保证窗口不会缩到空区间甚至左边界跑到右边界右边
        while (l <= r && sum > k)
        {
            sum -= a[l]; // 减去左边界元素
            l++;         // 左边界向右移动一位
        }

        // 经过上面的调整后，如果当前窗口 [l, r] 的和恰好等于 k，计数加 1
        if (sum == k)
        {
            ans++;
        }
    }

    cout << ans << "\n"; // 输出符合条件的子段个数
    return 0;
}
```
