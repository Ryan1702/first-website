# 有序数组去重

## 题目描述

给定一个长度为 $n$ 的非递减整数数组 $a_1, a_2, \dots, a_n$，请在原数组上去重：相同的元素只保留一个，并输出去重后的元素个数与去重后的数组。数组可能为空。

## 输入格式

第一行一个整数 $n$。

第二行 $n$ 个整数 $a_1, a_2, \dots, a_n$（$n = 0$ 时这一行为空）。

## 输出格式

第一行一个整数 $\text{len}$，表示去重后的元素个数。

第二行 $\text{len}$ 个整数，表示去重后的数组，相邻整数之间用一个空格分隔（$\text{len} = 0$ 时输出一个空行）。

## 数据范围

- $0 \le n \le 2 \times 10^5$
- $|a_i| \le 10^9$
- 输入保证数组非递减

## 样例

```text title="样例输入"
6
1 1 2 2 3 4
```

```text title="样例输出"
4
1 2 3 4
```

## 思路

数组本身有序，相等的元素一定相邻，用一个快慢指针一次扫描即可：

- $\text{slow}$ 指向去重后序列的最后一个元素（初始为 $0$）；
- $\text{fast}$ 从下标 $1$ 开始扫描，只要 $a[\text{fast}] \ne a[\text{slow}]$，说明遇到了新元素，就让 $\text{slow}$ 后移一位并写入 $a[\text{fast}]$；
- 扫描结束后，去重后的长度就是 $\text{slow} + 1$。

时间复杂度 $O(n)$，额外空间 $O(1)$。

## 代码

```cpp
#include <bits/stdc++.h>
using namespace std;
int main()
{
    int n; // 数组长度
    cin >> n;

    // 处理空数组的边界情况
    if (n == 0)
    {
        cout << 0 << "\n\n";
        return 0;
    }

    vector<int> a(n); // 定义非递减有序数组
    for (int i = 0; i < n; i++)
    {
        cin >> a[i];
    }

    int slow = 0; // 慢指针：指向去重后序列的最后一个元素下标

    // 快指针 fast 从下标 1 开始扫描后续元素
    for (int fast = 1; fast < n; fast++)
    {
        // 只有当 a[fast] 与当前去重末尾 a[slow] 不相等时，才是新元素
        if (a[fast] != a[slow])
        {
            slow++;            // 慢指针前进一位，腾出新位置
            a[slow] = a[fast]; // 将新的不重复元素写入
        }
        // 若 a[fast] == a[slow]，说明是重复元素，跳过即可
    }

    int new_len = slow + 1; // 去重后有效元素的个数

    cout << new_len << "\n";
    for (int i = 0; i < new_len; i++)
    {
        if (i > 0)
        {
            cout << " ";
        }
        cout << a[i];
    }
    cout << "\n";

    return 0;
}
```
