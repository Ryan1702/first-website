# 无重复字符的最长子串

## 题目描述

给定一个不含空格的字符串 s，求其中不含重复字符的最长连续子串的长度。

## 输入格式

一行一个字符串 s（不含空格）。

## 输出格式

输出一个整数，表示最长无重复字符子串的长度。

## 数据范围

- 1 ≤ |s| ≤ 10^6
- s 只包含可见 ASCII 字符，且不含空格

## 样例

```text title="样例输入"
abcabcbb
```

```text title="样例输出"
3
```

**样例解释**

最长的合法子串是 `abc`、`bca`、`cab`，长度都是 3。

## 思路

用滑动窗口配合频次数组：

- 右指针 r 逐字符扩张，把 s[r] 的出现次数加一；
- 如果这个字符在当前窗口内出现次数超过 1，就不断把左指针 l 指向的字符移出窗口并减少计数，直到窗口内不再有重复字符；
- 此时窗口 [l, r] 就是一段合法的无重复子串，用 r - l + 1 更新答案。

每个字符最多进出窗口一次，时间复杂度 O(|s|)。频次数组开到 256，下标用 unsigned char 转换，避免字符为负导致越界。

## 代码

```cpp
#include <bits/stdc++.h>
using namespace std;
int main()
{
    string s; // 输入字符串
    cin >> s;

    int cnt[256] = {0}; // 频次数组，统计当前窗口 [l, r] 内各 ASCII 字符的出现次数
    int l = 0;          // 滑动窗口左边界
    int max_len = 0;    // 记录无重复字符子串的最大长度

    // 右指针 r 从左到右扩展窗口
    for (int r = 0; r < (int)s.size(); r++)
    {
        unsigned char ch_r = s[r]; // 转为 unsigned char 避免负下标越界
        cnt[ch_r]++;               // 将新字符纳入窗口，计数加 1

        // 如果当前字符在窗口内出现次数超过 1，说明存在重复
        // 不断移动左指针 l 并减少对应计数，直到窗口内不再有重复字符
        while (cnt[ch_r] > 1)
        {
            unsigned char ch_l = s[l];
            cnt[ch_l]--; // 左端字符移出窗口，计数减 1
            l++;         // 左边界右移
        }

        // 此时 [l, r] 一定是不含重复字符的合法子串，长度为 r - l + 1
        int cur_len = r - l + 1;
        if (cur_len > max_len)
        {
            max_len = cur_len;
        }
    }

    cout << max_len << "\n";
    return 0;
}
```
