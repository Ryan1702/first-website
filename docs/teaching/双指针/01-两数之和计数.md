# 两数之和计数

## 题目描述

给定一个长度为 $n$ 的整数序列 $a_1, a_2, \dots, a_n$，以及一个整数 $k$。请统计有多少对下标 $(i, j)$ 满足 $i < j$ 且 $a_i + a_j = k$。

## 输入格式

第一行两个整数 $n, k$，分别表示序列长度与目标和。

第二行 $n$ 个整数 $a_1, a_2, \dots, a_n$。

## 输出格式

一行一个整数，表示满足 $a_i + a_j = k$ 的数对个数。

## 数据范围

- $1 \le n \le 2 \times 10^5$
- $-10^9 \le a_i \le 10^9$
- $|k| \le 2 \times 10^9$

## 样例

```text title="样例输入"
6 5
1 4 2 4 3 1
```

```text title="样例输出"
5
```

**样例解释**

排序后序列为 $1, 1, 2, 3, 4, 4$。和为 $5$ 的数对来自 $(1, 4)$ 与 $(2, 3)$：前者有 $2 \times 2 = 4$ 对，后者有 $1 \times 1 = 1$ 对，共 $5$ 对。

## 思路

先把序列升序排序，再用左右两个指针从两端向中间夹：

- 若 $a[l] + a[r] < k$，当前和偏小，只有让左指针右移才能增大和；
- 若 $a[l] + a[r] > k$，当前和偏大，只有让右指针左移才能减小和；
- 若恰好相等，就统计左侧与 $a[l]$ 相同、右侧与 $a[r]$ 相同的元素个数 $\text{left\_cnt}$ 与 $\text{right\_cnt}$，一次贡献 $\text{left\_cnt} \times \text{right\_cnt}$ 对数，然后两指针同时内收；
- 若某一刻 $a[l] = a[r]$，说明区间内元素全部相同，直接从 $\text{cnt}$ 个里任选两个（$\binom{\text{cnt}}{2}$）后结束。

排序 $O(n \log n)$，两个指针各自最多走 $n$ 步，总复杂度 $O(n \log n)$。数对个数最大可达 $\dfrac{n(n-1)}{2}$，需要用 `long long` 保存。

## 代码

```cpp
#include <bits/stdc++.h>
using namespace std;
int main()
{
    int n, k;      // n 表示数组长度，k 表示目标和
    cin >> n >> k; // 读入 n 和 k

    vector<int> a(n); // 定义长度为 n 的整型数组 a
    for (int i = 0; i < n; i++)
    {
        cin >> a[i]; // 逐个读入数组元素
    }

    // 第一步：将数组从小到大排序
    // 排序后才能根据 sum 与 k 的大小关系，决定移动左指针还是右指针
    sort(a.begin(), a.end());

    long long ans = 0; // 用 long long 防止数对数量较大时发生 int 溢出
    int l = 0;         // 左指针，从数组最左端（下标 0）开始
    int r = n - 1;     // 右指针，从数组最右端（下标 n-1）开始

    // 当左指针在右指针左侧时持续查找（数对要求两个不同位置的元素，所以 l < r）
    while (l < r)
    {
        int sum = a[l] + a[r]; // 计算当前左右指针所指元素的和

        if (sum < k)
        {
            // 当前和偏小：因为数组已升序，只有把左指针右移才能增大和
            l++;
        }
        else if (sum > k)
        {
            // 当前和偏大：只有把右指针左移才能减小和
            r--;
        }
        else
        {
            // sum == k，找到了符合条件的元素组合

            // 情况 A：左右指针指向的值相等
            // 因为数组有序，a[l] == a[r] 意味着从 l 到 r 之间的所有元素都等于 a[l]
            if (a[l] == a[r])
            {
                long long cnt = r - l + 1;  // 区间 [l, r] 内相等元素的总个数
                ans += cnt * (cnt - 1) / 2; // 从 cnt 个相同元素中任选 2 个的组合数
                break;                      // 中间所有元素都已统计完毕，直接结束循环
            }

            // 情况 B：左右指针指向的值不同（a[l] < a[r]）
            long long left_cnt = 1;  // 记录与当前 a[l] 相等的元素个数，至少有 a[l] 本身 1 个
            long long right_cnt = 1; // 记录与当前 a[r] 相等的元素个数，至少有 a[r] 本身 1 个

            // 向右统计连续与 a[l] 相同的元素（注意不能越过 r）
            while (l + 1 < r && a[l] == a[l + 1])
            {
                l++;        // 左指针移动到下一个相等元素
                left_cnt++; // 左侧相同元素计数加 1
            }

            // 向左统计连续与 a[r] 相同的元素（注意不能越过 l）
            while (r - 1 > l && a[r] == a[r - 1])
            {
                r--;         // 右指针移动到前一个相等元素
                right_cnt++; // 右侧相同元素计数加 1
            }

            // 左侧 left_cnt 个数中的任意一个，与右侧 right_cnt 个数中的任意一个配对，和都为 k
            ans += left_cnt * right_cnt;

            // 当前这批 left_cnt 和 right_cnt 的值已经全部配对完成，两指针继续向内收缩
            l++;
            r--;
        }
    }

    cout << ans << "\n"; // 输出满足条件的数对总数
    return 0;
}
```
