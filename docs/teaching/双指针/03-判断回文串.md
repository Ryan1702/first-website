# 判断回文串

## 题目描述

给定一个不含空格的字符串 s，判断它是否为回文串。回文串指正着读和反着读完全相同的字符串，例如 `abcba`。

## 输入格式

一行一个字符串 s（不含空格）。

## 输出格式

若 s 是回文串输出 `YES`，否则输出 `NO`。

## 数据范围

- 1 ≤ |s| ≤ 10^6
- s 只包含可见 ASCII 字符，且不含空格

## 样例

```text title="样例输入"
abcba
```

```text title="样例输出"
YES
```

## 思路

用左右两个指针分别指向字符串的首尾，逐对比较 s[l] 与 s[r]：

- 只要有一对字符不相等，就立刻返回 false；
- 相等则 l 右移、r 左移，直到 l ≥ r，说明所有对称位置都相同，返回 true。

只需要 O(|s|) 时间与 O(1) 额外空间。

## 代码

```cpp
#include <bits/stdc++.h>
using namespace std;
// 判断字符串 s 是否为回文串
// 使用 const string& 传参：既避免拷贝整个字符串浪费时间，又保证函数内不会意外修改 s
bool isPalindrome(const string &s)
{
    int l = 0;                 // 左指针，指向字符串第一个字符（下标 0）
    int r = (int)s.size() - 1; // 右指针，指向字符串最后一个字符（下标 size - 1）

    // 当左指针在右指针左侧时，逐对比较对称位置的字符
    while (l < r)
    {
        if (s[l] != s[r])
        {                 // 只要有一对字符不相等，就不是回文
            return false; // 提前结束并返回 false
        }
        l++; // 左指针向中间移动一位
        r--; // 右指针向中间移动一位
    }

    return true; // 所有对称字符都相等，是回文串
}
int main()
{
    string s; // 定义待判断的字符串
    cin >> s; // 读入字符串（不含空格；若含空格需改用 getline）

    // 调用判断函数并输出结果
    if (isPalindrome(s))
    {
        cout << "YES\n";
    }
    else
    {
        cout << "NO\n";
    }

    return 0;
}
```
