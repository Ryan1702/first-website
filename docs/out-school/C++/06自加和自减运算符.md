# 自加和自减运算符

``` c++
#include<bits/stdc++.h>
using namespace std;
int main()
{
    int a=5,b=7;
    /*
    ++或者--有两层作用

    1.对变量本身的加一或减一操作

    2.整个语句的值即例如(a++)的值
    这个值跟++或者--在变量名前后有着直接关联
    如果++或--在变量名之前，则意味着这个值是先加一或者先减一，后再取值
    如果在之后，则意味着这个值先不发生变化，先进行取值，后再加一或者减一
    */
    cout<<(a++)+(--b)<<endl;
    cout<<a<<endl;//a为6
    cout<<b<<endl;//b为6
    cout<<(--a)-(b--)<<endl;
    cout<<a<<endl;//a为5
    cout<<b<<endl;//a为5
    return 0;
}
```
