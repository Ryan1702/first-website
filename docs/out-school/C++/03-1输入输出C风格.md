# 输入输出C风格

``` c++
#include<bits/stdc++.h>
using namespace std;
int main()
{
    int a,b;
    scanf("%d%d",&a,&b);
    printf("两个数的和为%d\n两个数的差为%d\n",a+b,a-b);
    /*
    scanf & printf 对比

    1.scanf不注重双引号部分的空格和换行，因为会自动忽略
    所以在输入多个数据，哪怕不在同一行，都可以写成形如scanf("%d%d%d%d",&a,&b,&c,&d);类似的形式
    并且scanf要注意加&（取地址符）

    注意输入float时用%f
    输入double时用%lf
    输入char时用%c

    2.printf注重双引号部分的空格和换行，双引号部分中的内容将原封不动的输出（除了%或者\开头的转义部分）
    取n位小数的printf写法：printf("%.nf\n",a);
    取整数的printf写法：printf("%.f\n",a);
    例如
    题目要求保留两位小数则就要写
    printf("%.2f\n",a);

    注意输出float和double时都用%f
    输出char时用%c
    */
    return 0;
}
```
