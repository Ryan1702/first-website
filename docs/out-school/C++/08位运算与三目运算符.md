# 位运算与三目运算符

``` c++
#include<bits/stdc++.h>
using namespace std;
int main()
{
    // 熟练掌握二进制之后，开始学习位运算
    /*
    & 与
    将两个数分别转化为二进制数
    对这两个二进制数的对应位置进行&（与操作）
    即对于当前这一位
    只有当二者都为1时结果为1
    其他结果均为0
    这个结果位于答案的对应位置上

    | 或
    将两个数分别转化为二进制数
    对这两个二进制数的对应位置进行|（或操作）
    即对于当前这一位
    二者只要有一个1
    则结果为1否则为0
    这个结果位于答案的对应位置上

    ^ 异或
    有两种理解方式

    第一种
    在或的基础上
    从原来的“二者只要有一个1”改为“二者恰好有一个1”

    第二种
    异或就是二进制的不进位加法

    ~ 取反
    按位取反
    计算机里的数据按照补码存储

    补码
    正数的反码，补码都是原码

    负数的反码是其正数部分的原码非符号位所有位取反
    负数的补码是负数的反码加一

    所以被操作数的补码按位取反后得到的结果是最后答案的补码

    << 左移
    所有二进制位往左挪一位
    即相当于*2的效果

    >> 右移
    所有二进制位往右挪一位
    即相当于/2的效果

    , 逗号
    隔开多个赋值语句
    最后整个部分返回的结果是逗号隔开的最后一个部分的值

    A?B:C 三目运算符
    A是条件语句
    如果A成立，结果是B
    如果A不成立，结果是C
    */
    int a=10,b=7;
    cout<<(a&b)<<endl;
    cout<<(a|b)<<endl;
    cout<<(a^b)<<endl;
    cout<<(~a)<<endl;
    cout<<(a<<2)<<endl;
    cout<<(b>>1)<<endl;
    a&=2;
    a|=2;
    b^=2;
    b<<=1;
    a>>=2;
    int c=(a=5,b=10);
    cout<<c<<endl;
    cout<<((1==2)?"Yes":"No")<<endl;
    return 0;
}
```
