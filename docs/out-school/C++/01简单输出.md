# 简单输出

``` c++
#include<bits/stdc++.h>
using namespace std;
int main()
{
    // endl = end of line 换行符
    // 在用cin和cout的时候要注意用连接符>>（cin）或者<<（cout）连接各个输入或者输出部分
    // 带有双引号的部分属于直接输出，例如想要输出换行就cout<<"\n";或者cout<<endl;
    // 想要输出空格就可以cout<<" ";
    // 总而言之，想要原封不动的输出就用双引号
    // 如果没有用双引号默认这一部分为变量名（可能为多个字母）
    cout<<"Hello World!"<<endl;
    // \n是一个字符，这个字符的名字叫换行符，作用类比endl
    printf("Hello World!\n");
    return 0;
}
```
